# 대한민국 임대주택 스마트 파인더 (Rental Housing Finder)

> **"내가 살고 있는 곳, 일하는 곳에서 신청할 수 있는 임대주택은 무엇이고 몇 순위일까?"**  
> 거주지, 직장 위치, 희망 지역과 개인 상세 조건(계층, 가구원수, 소득, 자산)을 입력하여 **신청 가능한 임대주택 유형과 청약 순위(1·2순위)를 자가진단**하고, **공식 청약 사이트의 실시간 공고를 즉시 확인**할 수 있는 웹 애플리케이션입니다.

---

## 🚀 빠른 시작 (실행 방법)

별도의 복잡한 설치 과정 없이 즉시 브라우저에서 사용할 수 있습니다.

### 방법 1: 브라우저로 바로 열기
- 파일 탐색기에서 아래 경로의 `index.html`을 더블 클릭하여 크롬, 엣지 등의 브라우저로 엽니다:
  ```
  C:\Users\Like\.gemini\antigravity\scratch\rental-housing-finder\index.html
  ```

### 방법 2: 로컬 웹 서버로 띄우기 (선택사항)
터미널(PowerShell)에서 아래 명령어를 실행하면 로컬 서버로 접속할 수 있습니다:
```powershell
cd C:\Users\Like\.gemini\antigravity\scratch\rental-housing-finder
python -m http.server 3000
# 또는
npx serve .
```
브라우저에서 `http://localhost:3000` 접속

## 🌟 주요 기능 및 폼 구성

### 1. 지역 및 생활권 기반 순위 자동 판정
- **현재 거주지** vs **직장/학교 소재지** vs **신청 희망 지역** 비교
- **1순위 (최우선 공급)**: 희망 자치구에 거주하거나 직장·학교가 있는 경우
- **2순위 (연접 지역)**: 희망 자치구와 경계를 맞닿은 인접 시·군·구 거주/직장자
- **3순위 (광역/관외)**: 수도권 또는 전국 일반공급 대상

### 2. 정밀한 입주자격 진단 폼
- **신청자 계층**: 대학생, 청년(만19~39세), 신혼부부(혼인 7년 이내/예비), 신생아 가구, 고령자, 다자녀, 일반
- **가구원수별 소득 기준표**: 2024~2026년 최신 도시근로자 월평균소득(50%, 70%, 100%, 120%, 150%) 실시간 자동 환산 및 슬라이더 연동
- **자산 및 차량 기준**: 총자산(2.73억 / 3.45억) 및 자동차가액(3,708만원 이하) 체크
- **청약통장 납입 횟수**: 6회/24회 이상 및 무주택세대구성원 조건 판정

### 3. 주택 유형별 적격성 리포트 & 실시간 공고 원클릭 이동
- 행복주택, 청년매입임대, 서울 청년안심주택, 국민임대, 통합공공임대, 장기전세, 공공지원 민간임대 적격 여부 카드 제공
- 각 주택 유형에 해당하는 공식 기관 공고 페이지로 바로 이동 가능한 링크 제공
